# Casino Mod for Mindustry

A simple casino mod for Mindustry where the player chooses an item to bet and receives a random reward.

## What the mod does
- Adds a casino feature to the game
- The player selects an item to bet
- After pressing the button, a random result occurs
- Depending on the chance, the player may receive an item, the same item, or nothing

## How to install
1. Download the mod archive
2. Place the mod folder into `Mindustry/mods/`
3. Start the game
4. Find the new casino block or interface
5. Choose an item and press the button

## Requirements
- Mindustry version 160.5+
- This mod was tested on version 160.5

## How to use
1. Place the casino block on the map
2. Select an item to bet
3. Press the button
4. Check the result and receive the reward

- Language: JavaScript
- Type: script mod
- Supported game: Mindustry

# Казино мод для Mindustry

Простой мод казино для игры Mindustry, где игрок выбирает предмет для ставки и получает случайный выигрыш.

## Что делает мод
- Добавляет в игру казино
- Игрок выбирает предмет, который ставит
- После нажатия кнопки происходит случайный результат
- В зависимости от вероятности игрок может получить предмет, такой же предмет или ничего

## Как установить
1. Скачайте архив мода
2. Поместите папку мода в директорию `Mindustry/mods/`
3. Запустите игру
4. Найдите новый блок или интерфейс казино
5. Выберите предмет и нажмите кнопку

## Требования
- Mindustry версии 160.5+
- Данный мод был протестирован на версии 160.5

## Как использовать
1. Разместите блок казино на карте
2. Выберите предмет для ставки
3. Нажмите кнопку
4. Проверьте результат и получите награду
